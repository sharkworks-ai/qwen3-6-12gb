Dataset manager

Record files, origins and licenses in a manifest (a JSON record with file hashes). Files must already exist in the container. This page does not upload data, create mixtures or test benchmark overlap. See supported data examples.

Examples: files ["/data/datasets/train.jsonl"]; origins ["owner/dataset@revision"]; licenses ["Apache-2.0"]. The manifest is saved under datasets/manifests. An empty file list records no file hashes.
