Run a miniature hybrid Qwen MoE through training, baseline evaluation, B and C, QAT, re-quantization and packed inference. A planned checkpoint interruption tests restart. Synthetic data tests the process; it does not establish coding quality.

Single-GPU proof

Defaults build about 160M parameters. Short sequences keep the first test small. Native context remains 262144, but this run does not test that length.

Stage logs and checkpoints live under the configured output directory. Watch the Runs page, then open the report here. A failed memory or parity check remains visible even if all stages finish.

Full-model validation on 5090s

Use your merged checkpoint, real AYOT traces, recovery data and a separate held-out corpus. This workflow runs both compression pipelines and packed inference, then repeats long-context needle checks. It can be expensive.

Baseline evaluation uses GPU/CPU offload. Packed inference uses one GPU. The eager packed runtime has bounded decode memory and does not have fused production kernels. Coding/tool benchmarks must run in isolated harnesses; import their results with artifact hashes and harness revisions.
